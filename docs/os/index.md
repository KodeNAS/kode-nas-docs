# KODE OS

KODE OS is the operating system that runs on your pebble. It's a fork of the
open-source [CasaOS](https://github.com/IceWhaleTech/CasaOS) project, tuned
for KODE NAS hardware and built around one idea: **your pebble should feel
like a finished appliance, not a Linux dashboard**.

You don't need to know what Docker or Samba or SSH are. The dashboard handles
all of that for you. These pages cover the parts you might want to know.
