# KODE NAS Pebble

The **pebble** is the hardware that runs KODE OS. It's a small home server,
roughly the size of a paperback book, designed to live quietly on a shelf or
a desk. One ethernet cable, one power cable, and it's your own private
cloud.

These pages cover the hardware itself — what's in the box, what's inside the
case, and how to physically set it up.
